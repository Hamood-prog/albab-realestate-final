الباحث العقاري – نسخة تطبيق ويب قابلة للتثبيت (PWA)

طريقة النشر على GitHub Pages:
1) فك ضغط الملف.
2) ارفع جميع الملفات الموجودة داخله إلى المجلد الرئيسي (root) للمستودع GitHub، مع استبدال الملفات القديمة عند السؤال.
3) افتح المستودع: Settings > Pages.
4) اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، ثم Save.
5) انتظر اكتمال النشر وافتح رابط GitHub Pages عبر HTTPS.

طريقة التثبيت على Android:
1) افتح رابط التطبيق المنشور باستخدام Chrome.
2) من قائمة ⋮ اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3) افتح التطبيق من الأيقونة. سيعمل دون اتصال بعد تحميله أول مرة واكتمال التخزين المؤقت.

ملاحظات:
- يجب نشر التطبيق عبر HTTPS (مثل GitHub Pages) حتى تعمل خدمة التثبيت والعمل دون إنترنت.
- لا تفتح index.html مباشرة من مدير الملفات؛ افتحه من رابط الموقع المنشور.
- بيانات السجلات التي يستوردها المستخدم تبقى ضمن تخزين المتصفح/الجهاز بحسب آلية التطبيق. لا تحذف بيانات الموقع أو ذاكرة التطبيق قبل أخذ نسخة احتياطية.
- تم تحديث اسم ذاكرة التخزين المؤقت لضمان تحميل النسخة الجديدة بعد النشر.
